Few-shot prompting is useful when a task needs a consistent format, tone, or specific examples. In Task 1, examples helped demonstrate how transactions should be classified, but misleading examples changed one of the categories incorrectly. This showed me that example quality is important. In Task 2, misleading examples affected the AI's classification. In Task 3, polite sample replies helped the AI maintain a professional and non-committal tone. Zero-shot prompting is enough for simple tasks with clear instructions. Few-shot prompting is worth the extra effort when examples improve consistency, but all examples must be checked carefully.
